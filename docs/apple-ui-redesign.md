# Apple 应用风格前端改版

本次仅修改现有前端体验。用户确认的方向是浅灰背景、白色内容区、系统字体、蓝色操作、窄侧栏及紧凑手机导航。现有纸质手账式米绿配色、宋体标题、装饰英文和多重工具边框收敛为统一的应用界面。

## 实现与范围

- `AppFrame` 管理登录/认证后的统一外壳。桌面 224px 侧栏包含六个主导航、账户操作和服务状态，阅读区限制宽度；手机改用可横向滚动的单行导航，保留全部入口。选中项同时用背景和 `aria-current` 表达。
- 登录页使用独立居中表单；日记、日历、归档、标签、导出、账户和回收站共用颜色、圆角、字级、输入与按钮规则。图标是随源码提供的 SVG，无远程字体、装饰图片或新增运行依赖。
- “标签与图片”默认收起，原组件保持挂载；展开不发起写请求。已有选中标签或附件的编辑/恢复草稿初始展开。工具展开状态保留至编辑表单重建，保存成功后回到收起的新草稿。组合输入、上传或保存期间禁止展开/收起。
- 原 `AuthGate` 的会话、写锁、草稿、冻结创建 UUID 和冲突处理继续沿用；切换视图保留同一日记编辑器，401 移除私密 DOM。标签创建输入和图片选择不会因工具收起丢失。
- 保留 Markdown 原文与独立预览，样式改用统一变量。无数据库迁移、API、导出格式或新闻/AI 变更。

样式入口 `apps/web/src/styles.css` 记录 finesse 的 Apple app 模式。`.finesse/log.json` 为本机设计历史，按技能要求忽略；CSS 标记随源码保留。

## 运行

沿用根 README 的后端启动方式；已有后端运行时，在仓库根目录执行：

```sh
cd apps/web
# 尚未安装依赖时执行，版本沿用锁文件：
npm ci --registry=https://registry.npmmirror.com
npm run dev
```

打开 `http://127.0.0.1:5173`。后端不在默认 `8000` 端口时，使用 `API_PROXY_TARGET=http://127.0.0.1:端口 npm run dev`。已有 Vite 开发进程使用其原地址即可。Compose 部署仍按根 README 构建，不需要迁移。

## 可复核的检查

在 `apps/web` 执行：

```sh
npm run typecheck
npm run lint
npm run format:check
npm test
npm run build
```

然后回到仓库根目录执行：

```sh
node scripts/check-ui-layout.mjs
git diff --check
```

布局脚本需要 Node 24 和 Chrome。macOS 默认使用标准安装路径；其他位置设置 `CHROME_BIN`，Linux 默认 `google-chrome`。只读服务构建目录，在随机 loopback 端口提供合成 API 数据，使用新建临时 Chrome 配置；退出关闭测试服务器和 Chrome，保留临时配置供诊断，不读取或改变日常浏览器配置。脚本不接收现有实例 URL。除合成登录外，任何写 API 请求都会使检查失败。

第一轮旧测试有 10 项直接操作默认展开的工具，已补充真实用户的展开步骤；复核全量 131 项通过。没有降低既有上传、会话失效、CAS 或创建重试断言。

浏览器检查是合成数据的 DOM、几何和计算样式验收，未做截图审美评审；本次未运行完整真实 API/Compose 恢复测试，也未新增真实设备、系统输入法或软键盘的验收证据。桌面低高度下侧栏可独立滚动；手机主导航可横向滑动，键盘焦点也可进入每项。
