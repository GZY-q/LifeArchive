## 固定契约

- 新增 `POST /api/v1/journal-export`，严格 JSON `{include_deleted?: boolean}`，默认 false。复用 owner、Origin/JSON/自定义头/CSRF/no-store；不接受 owner、路径、文件名或任意筛选参数。
- 返回200 `application/zip` 附件，固定安全文件名 `life-archive-journal.zip`。复用v4格式、所选日记全部修订和当前/历史引用原图；默认排除软删除，可显式包含；未关联上传/认证/日志/配置不导出。
- 复用独立 `REPEATABLE READ, READ ONLY` 快照和全部哈希核验，限定为已认证 owner。原文/日期/修订/标签/附件/置顶/会话不写入。CLI 排他创建、0600和失败残留行为保持。
- 网页导出使用有界内存缓冲，不落服务端文件。上限1000篇所选日记、5000条所选修订、2000个目录标签和32MiB压缩ZIP；任一超限413/export_too_large，完整档案继续用CLI。每进程最多一个请求生成/发送，忙碌429/export_busy，不引入分布式锁或任务表。
- 生成与校验采用30秒协作式时限，每条SQL最多3秒；超时504/export_timeout，媒体缺失/损坏、核验或数据库失败503/export_unavailable。完整校验前不发送附件头或字节，失败不生成可下载URL；没有持久化失败工件，重试重新读取快照，不自动重试。

## 前端

- 主导航增加“导出”，默认只选活动日记，明确说明修订/原图、未关联上传和未加密私密ZIP的范围。显式生成，成功后显示下载链接和实际采用的删除策略。
- 请求使用现有client，ZIP Accept和45秒超时只对该调用生效。选项或重新生成使旧链接失效；离开页面/会话退出时撤销Blob URL并中止读取，迟到响应不生成链接。
- 导出为只读，不锁定导航/日记；生成期间禁止重复生成和切换选项。401沿用登录保护，同页日记草稿/编辑器/附件/冻结UUID/409状态保持。没有自动生成、自动下载、localStorage或URL私密条件。
